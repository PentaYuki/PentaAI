## 🏛️ Cây Thư Mục Phân Tách

```text
pentajob/dataset/ (hoặc datasheet/)
├── job_categories/         # Danh mục nghề nghiệp (Công nghệ, Kế toán, Kinh doanh, Giáo dục...)
├── skill_matrices/         # Ma trận kỹ năng chuẩn hóa (Hard skills & Soft skills)
├── mock_interviews/        # Ngân hàng câu hỏi phỏng vấn giọng nói theo thang điểm 100
└── salary_benchmarks/      # Báo cáo dải lương thị trường theo năm kinh nghiệm
```
