# Shared Library (`shared`)

Thư viện và định nghĩa dùng chung cho tất cả các hệ thống con trong hệ sinh thái **PentaKurumi**.

## Nội Dung Bao Gồm
- Định nghĩa kiểu dữ liệu thống nhất (Data Transfer Objects - DTOs, TypeScript interfaces, Python Pydantic models).
- Chuẩn giao thức cho bộ ba chunk: `chunk emo`, `chunk time`, `chunk action`.
- Cơ chế tạo và xác thực `UnifiedApiKey`.
- Mã lỗi và hằng số hệ sinh thái.
